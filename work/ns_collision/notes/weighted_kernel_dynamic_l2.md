# Square-tilted dynamic L2 kernel

## Purpose

The nonautonomous affine visit has no fixed reversible Gaussian measure. A
fixed-measure conversion is unnecessary: every positive Feynman-Kac kernel
has a canonical dynamic exit law for which its `L2` norm is exactly the
`L2` size of one scalar constant-payoff function.

This is an exact operator identity. It reduces, but does not yet close, the
nonautonomous boundary theorem.

## Exact identity

Let `K` be any positive kernel from an entry boundary `X` to an exit boundary
`Y`:

```text
Kf(x)=int_Y K(x,dy)f(y),
m(x)=K1(x).                                           (1)
```

Let `mu` be any probability law on `X`, and define

```text
A=int_X m(x)^2 mu(dx).                                (2)
```

When `A>0`, define the square-tilted exit law

```text
nu(dy)=A^(-1) int_X mu(dx)m(x)K(x,dy).                (3)
```

Its mass is one because the integral of the numerator is `A`. Positivity and
Cauchy-Schwarz give

```text
|Kf(x)|^2<=K1(x) K(f^2)(x)=m(x)K(f^2)(x).             (4)
```

Integrating (4) against `mu` and using (3),

```text
||Kf||_(L2(mu))^2<=A ||f||_(L2(nu))^2.                (5)
```

The constant function `f=1` attains equality. Therefore

```text
||K||_(L2(nu)->L2(mu))
 =sqrt(A)=||K1||_(L2(mu)).                            (6)
```

For two independent replicas, the kernel is `K tensor K`, the laws are
product laws, and the exact norm is `A`, the square of the one-history gain.

If `K` is an ordinary conservative Markov kernel, `m=1`, `A=1`, and (3) is
the usual pushed-forward law. Thus (6) strictly extends the dynamic Markov
contraction already used for relabeling.

## Consequence for the compact visit

Let

```text
g=||K1||_(L2(entry law)).                             (7)
```

The earlier compact static calibration gave the bare-halving coefficient
`0.51612361`. The current cubic parent-child recentering factor raises the
complete coefficient to

```text
C_dynamic=0.658695038668 g^2.                         (8)
```

Therefore the ideal cycle closes whenever

```text
g<1.23213361.                                         (9)
```

Under the legacy bare-halving coefficient, a gain `g<=1` would leave
`C_dynamic<=0.516124`. The rotating-affine point diagnostic `g≈0.5909`
would correspond to `C_dynamic≈0.1802`, although that Monte Carlo value is
not a bound and is for one starting point rather than a complete entry law.
Under the current coefficient the corresponding values are `0.658695` and
approximately `0.2300`.

## What this repairs

The boundary law in (3) is constructed from the actual weighted visit. No
Radon-Nikodym comparison with a static Gaussian boundary measure is needed,
and no singular hitting law causes an automatic infinite conversion factor.
Subsequent ordinary diffusion, relabeling, and child transitions push this
dynamic probability law forward contractively.

The price is explicit and honest: the proof must now control the scalar
constant-payoff function `m=K1` in the current entry law. A uniform pointwise
bound is sufficient but not logically necessary.

## Remaining gate

For the instantaneous full-affine baseline, prove

```text
||K1||_(L2(mu))<1.23213361                            (10)
```

for every dynamic entry law generated by the cycle, uniformly over the
admissible measurable strain history. Then extend (6) through the spatial
Campanato and strain perturbations. The generous threshold in (10) suggests
that a coarse scalar supersolution or an energy-to-trace estimate may be
enough; reproducing the static Gaussian norm is unnecessary.
